# 📄 Rakit CV — Pembuat CV ATS Gratis

### Isi form → CV rapi ramah-ATS → unduh PDF (teks asli, lolos pemindai). Gratis, tanpa login, 100% di browser.

**[▶ Buka Rakit CV](https://ksatriabintangsamudra.my.id/cv/)**

</div>

---

Banyak lamaran kerja disaring dulu oleh **ATS** (Applicant Tracking System) sebelum dilihat manusia. CV yang penuh kolom, tabel, ikon, dan foto sering gagal terbaca. **Rakit CV** menghasilkan CV yang:

- **Satu kolom, judul seksi standar, teks asli** — bukan gambar — jadi mudah dibaca ATS.
- **Rapi & profesional** — gaya serif klasik dengan aksen warna pilihanmu.
- **PDF berteks** (bukan hasil screenshot), sehingga isinya bisa disalin & dipindai.

## Fitur

- ✍️ **Form lengkap**: data diri, ringkasan, pengalaman, proyek, pendidikan, keahlian, sertifikasi, bahasa.
- 👁 **Pratinjau A4 real-time** — perubahan langsung terlihat.
- 🎨 **5 pilihan warna aksen** (tetap ramah-ATS).
- 🔁 **Tambah/hapus/urut** tiap entri; penghitung jumlah halaman.
- 💾 **Tersimpan otomatis** di perangkat (localStorage) + **ekspor/impor JSON** untuk lanjut di lain waktu.
- 🖨️ **Unduh PDF** teks asli lewat dialog cetak → *Save as PDF*.
- 🔒 **Privat**: semua diproses di browser — datamu tidak pernah dikirim ke server mana pun.

## Teknologi

HTML + CSS + JavaScript murni, tanpa framework, tanpa build step. Ekspor PDF memakai pipeline cetak bawaan browser (mempertahankan teks asli agar lolos ATS). Deploy statis di GitHub Pages / Cloudflare.

## Menjalankan lokal

```bash
python3 -m http.server 8080   # lalu buka http://localhost:8080
```
